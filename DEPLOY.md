# Как залить сайт на REG.RU

## 1. Собрать папку для загрузки

```bash
bash tools/compress-media.sh   # один раз: сжатые видео, картинки, иконки (нужен ffmpeg)
bash tools/build-dist.sh       # создаёт dist/ — только то, что идёт на хостинг
```

В `dist/` лежит всё нужное: `index.html`, `send.php`, `.htaccess`, иконки, `css/`, `js/`, `fonts/` (шрифты локально), `images/` (сжатые), `video/web/`, `video_reels/web/`. Оригиналы видео 1080×1920 туда не попадают.

## 2. Перед загрузкой вписать, куда приходят заявки

Откройте `dist/send.php` и заполните константы в начале файла (хотя бы одну):

- `MAIL_TO` — почта для заявок;
- `TG_BOT_TOKEN` и `TG_CHAT_ID` — Telegram-бот (токен от @BotFather, chat_id получателя или группы).

Пока они пустые, форма показывает «Не удалось отправить заявку…» с номером телефона.

## 2б. Ссылка-превью в мессенджерах

Telegram/WhatsApp надёжно показывают картинку только по полному адресу. Когда домен известен, в `dist/index.html` замените
`<meta property="og:image" content="og-image.jpg">` на `<meta property="og:image" content="https://ВАШ-ДОМЕН/og-image.jpg">`.
Это единственное место, где нужен абсолютный адрес.

## 3. Загрузить на хостинг

1. Панель ISPmanager → «Менеджер файлов» → папка сайта `www/<ваш-домен>/`.
2. Загрузите **содержимое** `dist/` (не саму папку `dist`) прямо в `www/<ваш-домен>/`. Быстрее всего: заархивировать содержимое `dist/` в zip → загрузить архив → «Извлечь» → удалить архив.
   Через FTP (FileZilla): данные FTP — в письме REG.RU или в панели «FTP-пользователи»; перетащить содержимое `dist/` в `www/<ваш-домен>/`.
3. Файл `.htaccess` начинается с точки — на Mac он скрыт (Cmd+Shift+. в Finder показывает его). Проверьте, что он загрузился.
4. В панели: «SSL-сертификаты» → выпустить бесплатный Let's Encrypt для домена и `www.` — **до** проверки сайта, иначе редирект на https приведёт на ошибку.

## 4. Проверить

- Открыть `http://www.<домен>` → должен перебросить на `https://<домен>`.
- Нажать «ЗАПИСАТЬСЯ», отправить тестовую заявку → «Заявка отправлена, мы вам перезвоним», письмо/сообщение пришло.
- Ссылку на сайт отправить себе в Telegram/WhatsApp → видна картинка-превью.
